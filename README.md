# 🔬 ResearchMind

ResearchMind is a **multi-agent AI research assistant** built with **LangChain** and **Streamlit**. It automates the research workflow by using specialized AI agents to search the web, extract relevant information, generate a structured research report, and critique the final output.

## ✨ Features

* 🔍 Web search for recent information
* 📄 Intelligent content extraction
* ✍️ AI-generated research reports
* 🧐 Automated report review and feedback
* 🎨 Clean, interactive Streamlit interface

## 🛠️ Tech Stack

* Python
* LangChain
* Streamlit
* Tavily Search API
* Large Language Models (LLMs)

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📌 Workflow

**User Query → Search Agent → Reader Agent → Writer Chain → Critic Chain → Final Research Report**

Built as a demonstration of autonomous multi-agent systems for AI-powered research.
